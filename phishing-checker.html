Bulgarian Phishing Domain Checker

Got a suspicious link in a text message or email? Paste the website address below to see whether it appears in a public list of phishing domains that imitate Bulgarian courier companies (Econt, Speedy, Bulgaria Post), the Ministry of Interior e-services portal and the toll and vignette services.

How to read the result

  • Found in the list: do not open the link and do not enter any information.
  • Not found: this does not mean the site is safe. New phishing sites appear every day, and this list only covers a few Bulgarian brands. Never enter passwords or card details through a link you received. Open the official website or app yourself instead.

About the data

The list comes from the public Detectopod threat feed, which scans for look-alike domains automatically and is updated regularly. Automated detection can make mistakes, so treat a match as a strong warning and not as proof.

Your input is checked in your own browser and is not sent to this site. When the page opens, it downloads the public list from GitHub.

This tool only compares an address with a list. It is not a security scan.
